---
title: "Démarrage rapide"
description: "Déployer une instance Komamy en local ou en production avec Docker"
---

Ce guide vous amène d'un dépôt vide à une instance Komamy fonctionnelle. Deux chemins possibles : **Docker** (recommandé, décrit ici) ou une installation manuelle avec Bun + PostgreSQL (voir [Déploiement](/developpeurs/deploiement) pour le détail complet, les variables d'environnement et le déploiement sans Docker).

## Prérequis

- [Docker](https://docs.docker.com/get-docker/) et Docker Compose
- Le dépôt Komamy cloné localement

<Steps>
  <Step title="Créer les volumes persistants">
    Les volumes sont déclarés `external: true` dans `docker-compose.yml` — ils doivent exister avant le premier démarrage :

    ```bash
    docker volume create komamy-data
    docker volume create komamy-db-data
    ```

    <Note>
      Cette précaution évite qu'une plateforme de déploiement (Dokploy, Coolify, CapRover...) ne recrée le volume — et donc n'efface vos images — à chaque redéploiement. Voir [Déploiement](/developpeurs/deploiement#déploiement-via-dokploy--coolify--caprover--portainer) pour le détail.
    </Note>
  </Step>
  <Step title="Configurer l'environnement">
    ```bash
    cp .env.example .env
    ```

    Éditez au minimum `.env` :

    - `JWT_SECRET` — obligatoire en production (`openssl rand -base64 48`)
    - `ADMIN_USERNAME` / `ADMIN_PASSWORD` — identifiants du compte admin créé au premier démarrage
    - `POSTGRES_PASSWORD` — mot de passe de la base Postgres du conteneur
  </Step>
  <Step title="Démarrer la stack">
    ```bash
    docker compose up -d --build
    ```

    Deux conteneurs démarrent : `postgres` (PostgreSQL 16) et `komamy` (l'application). Au premier lancement, les migrations sont appliquées et le compte administrateur est créé automatiquement — aucune étape manuelle supplémentaire.
  </Step>
  <Step title="Se connecter">
    Ouvrez `http://localhost:3000` (port configurable via `PORT`) et connectez-vous avec les identifiants admin définis à l'étape 2 (ou les valeurs par défaut `admin` / `changeme123` si vous ne les avez pas changées).

    <Warning>
      Changez immédiatement le mot de passe admin par défaut depuis `/settings` une fois connecté.
    </Warning>
  </Step>
</Steps>
