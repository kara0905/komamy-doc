## Messagerie privée

Depuis `/chat`, trois types de conversation existent :

| Type | Description |
| --- | --- |
| **Directe** | 1:1 entre deux utilisateurs. Démarrez-en une depuis le profil de quelqu'un, ou via **Nouveau message** (recherche par pseudo). |
| **Groupe** | La conversation d'une équipe dont vous êtes membre — ses participants se synchronisent automatiquement avec les membres actuels de l'équipe. |
| **Support** | Ouverte automatiquement quand vous créez un [signalement](/guide-lecteur/signalements) — canal dédié avec le staff. |

Dans une conversation, vous pouvez éditer ou supprimer (masquer) vos propres messages — un message supprimé affiche un placeholder « Message supprimé » plutôt que de disparaître de l'historique. La liste des conversations est triée par activité récente, avec un compteur de messages non lus par conversation.

## Notifications

La cloche de notification liste vos alertes, plus récentes en premier, avec un compteur de non-lues. Chaque notification porte un lien direct vers le contenu concerné.

| Type de notification | Déclenchée par |
| --- | --- |
| Nouveau chapitre | Un projet que vous suivez (favori) publie un chapitre |
| Réponse à un commentaire | Quelqu'un répond à l'un de vos commentaires |
| Message reçu | Nouveau message dans une conversation |
| Mise à jour de ticket | Changement de statut sur l'un de vos signalements |
| Nouveau projet d'équipe | Une équipe que vous suivez publie un nouveau projet |
| Nouveau projet d'auteur | Un⋅e auteur⋅rice que vous suivez publie un nouveau projet |
| Nouveau billet de blog | Selon vos réglages de suivi communautaire |

### Personnaliser vos préférences

Depuis `/settings`, désactivez individuellement chaque **type** de notification — le réglage est **clairsemé** : par défaut tout est activé, seuls les types que vous désactivez explicitement cessent de générer une notification (les autres restent actifs même après l'ajout d'un nouveau type par une future mise à jour).
