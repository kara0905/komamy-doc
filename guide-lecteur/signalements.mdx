Le menu **Support**, accessible depuis la barre latérale (icône bouée), centralise toute demande adressée au staff — pas seulement les signalements de bug.

<Steps>
  <Step title="Choisir un sujet">
    Cliquer sur **Support** ouvre une sélection de sujets, chacun avec son propre formulaire adapté :

    <Frame>
      <img src="/images/guides/support-01-sujets.png" alt="Fenêtre Support : sélection du sujet de la demande" />
    </Frame>

    | Sujet | Usage |
    | --- | --- |
    | **Signaler un bug technique** | Affichage cassé, erreur, fonctionnalité qui ne marche pas. |
    | **Question sur mon compte** | Connexion, mot de passe, paramètres, données personnelles... |
    | **Proposer ou suivre une série** | Publier une série, rejoindre une équipe, signaler un souci sur une série existante — seul sujet avec un sélecteur de série. |
    | **Suggestion d'amélioration** | Une idée pour améliorer le site. |
    | **Autre** | Toute autre demande. |
  </Step>
  <Step title="Remplir le formulaire">
    Le formulaire s'adapte au sujet choisi (libellés, exemples de placeholder). Un champ **Capture d'écran** optionnel permet de joindre une image directement au ticket.

    <Frame>
      <img src="/images/guides/support-02-formulaire.png" alt="Formulaire de signalement de bug avec pièce jointe optionnelle" />
    </Frame>
  </Step>
  <Step title="Suivre la conversation">
    Chaque demande ouvre automatiquement un canal de **messagerie** dédié (type Support) avec le staff — retrouvez-le dans `/chat`. Vous êtes notifié à chaque changement de statut (Ouvert → En cours → En attente → Résolu → Fermé).
  </Step>
</Steps>

<Note>
  Un compte connecté est requis pour ouvrir une demande de support — cette fonctionnalité n'est pas accessible aux visiteurs anonymes. Les publications sont limitées en fréquence (anti-spam).
</Note>

## Signaler un commentaire ou un projet précis

En complément du menu Support général, un signalement peut aussi être ouvert **directement depuis un projet ou un commentaire** (menu contextuel « Signaler ») — pratique pour cibler précisément le contenu concerné plutôt que de le décrire dans un formulaire général. Ce chemin utilise le même mécanisme de ticket, avec le projet (et éventuellement le commentaire) déjà rattaché.

Pour la modération des signalements côté équipe/staff, voir [Administration](/guide-equipe/administration#tickets).
