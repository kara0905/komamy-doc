<Accordion title="/auth — Authentification & comptes" icon="key">

| Méthode | Route | Accès | Description |
| --- | --- | --- | --- |
| POST | `/auth/register` | Public | Crée un compte (`lecteur`). Body : `{ username, password }` (username 3-32 `[a-zA-Z0-9_-]`, password ≥ 8, rejeté si compromis — voir [Vue d'ensemble](/developpeurs/api-overview#mot-de-passe)). |
| POST | `/auth/login` | Public | Connexion. Body : `{ username, password }`. Pose le cookie de session, ou `{ requiresTotp: true }` si la 2FA est activée. |
| POST | `/auth/totp/login-verify` | Public | Étape 2 après un login mot de passe avec 2FA. Body : `{ code }`. Consomme le cookie temporaire posé par `/auth/login`. Pose le cookie de session. |
| POST | `/auth/logout` | Public | Révoque la session courante et supprime le cookie. Idempotent. |
| GET | `/auth/me` | Connecté | Profil de l'utilisateur courant. |
| POST | `/auth/avatar` | Connecté | Upload d'avatar. `multipart/form-data`, champ `avatar`. |
| POST | `/auth/banner` | Connecté | Upload de bannière de profil. `multipart/form-data`, champ `banner`. |
| POST | `/auth/change-password` | Connecté | Body : `{ currentPassword, newPassword }` (newPassword ≥ 8). Révoque toutes les autres sessions. |
| POST | `/auth/change-username` | Connecté | Body : `{ newUsername, password }`. Ré-émet le cookie de session avec le nouveau pseudo. |

**`PublicUser`** : `{ id, username, role, status, avatarUrl, bannerImageUrl, bio, createdAt, lastLoginAt }`.

### `/auth/totp` — 2FA

| Méthode | Route | Accès | Description |
| --- | --- | --- | --- |
| GET | `/auth/totp` | Connecté | Statut de la 2FA. |
| POST | `/auth/totp/setup` | Connecté | Confirmé par le mot de passe. Génère un secret (pas encore actif), porté par un cookie signé 5 min. Réponse : `{ secret, otpauthUrl, qrCodeDataUrl }`. |
| POST | `/auth/totp/confirm` | Connecté | Body : `{ code }`. Consomme le cookie posé par `/setup` et active la 2FA. |
| DELETE | `/auth/totp` | Connecté | Confirmé par le mot de passe. Désactive la 2FA. |

### `/auth/sessions` — appareils connectés

| Méthode | Route | Accès | Description |
| --- | --- | --- | --- |
| GET | `/auth/sessions` | Connecté | `{ sessions: PublicSession[] }`. La session ayant servi à la requête porte `current: true`. |
| DELETE | `/auth/sessions/:id` | Connecté | Révoque une session précise. 404 si elle n'appartient pas à l'appelant. |
| POST | `/auth/sessions/revoke-others` | Connecté | Révoque toutes les sessions sauf la courante. |

### `/auth/recovery` — récupération sans e-mail

| Méthode | Route | Accès | Description |
| --- | --- | --- | --- |
| POST | `/auth/recovery/redeem` | Public, rate-limité | Body : `{ username, code, newPassword }`. Échange un code contre un nouveau mot de passe. |
| GET | `/auth/recovery` | Connecté | `{ remaining }` — nombre de codes non utilisés restants. |
| POST | `/auth/recovery` | Connecté | Confirmé par le mot de passe. Régénère un lot de 10 codes (invalide l'ancien). Réponse : `{ codes: string[] }`, affichés **une seule fois**. |

### `/auth/passkeys`

| Méthode | Route | Accès | Description |
| --- | --- | --- | --- |
| GET | `/auth/passkeys` | Connecté | `{ passkeys: PublicPasskey[] }`. |
| POST | `/auth/passkeys/register-options` | Connecté | Options WebAuthn pour `navigator.credentials.create()`, challenge dans un cookie httpOnly 5 min. |
| POST | `/auth/passkeys/register-verify` | Connecté | Body : `{ response, name? }`. Réponse : `{ passkey: PublicPasskey }`. |
| POST | `/auth/passkeys/login-options` | Public | Options WebAuthn (flux discoverable, pas de `allowCredentials`). |
| POST | `/auth/passkeys/login-verify` | Public | Body : `{ response }`. Pose le cookie de session comme `/auth/login`. |
| PUT | `/auth/passkeys/:id` | Connecté | Renomme. Body : `{ name }`. |
| DELETE | `/auth/passkeys/:id` | Connecté | Supprime. |

`PublicPasskey` : `{ id, name, deviceType, backedUp, createdAt, lastUsedAt }`.

Catalogue des rôles globaux (voir [Rôles et permissions](/guide-equipe/roles-et-permissions)). Les 3 rôles intégrés (Admin/Modérateur/Lecteur) ne peuvent être ni renommés ni supprimés — seuls leurs bits sont modifiables.

| Méthode | Route | Description |
| --- | --- | --- |
| GET | `/admin/roles` | Tous les rôles globaux, avec leur nombre de porteurs. |
| POST | `/admin/roles` | Body : `{ name, color?, permissions: GlobalFlag[] }`. |

| DELETE | `/admin/roles/:id` | Refusé pour un rôle intégré. Retire le rôle de tous ses porteurs (cascade). |

#### Dérogations de permissions (`/admin/projects/:slug/overrides`)

Réservé à `MANAGE_ROLES` — volontairement **non délégable** aux équipes, même à leur propriétaire (voir [Rôles et permissions](/guide-equipe/roles-et-permissions#dérogations-de-permissions-par-projet)).

| Méthode | Route | Description |
| --- | --- | --- |
| GET | `/admin/projects/:slug/overrides` | `{ overrides: PublicProjectMemberOverride[] }`. |
| PUT | `/admin/projects/:slug/overrides/:userId` | Body : `{ allow: TeamFlag[], deny: TeamFlag[] }`. Pose ou remplace la dérogation. |
| DELETE | `/admin/projects/:slug/overrides/:userId` | Retire la dérogation. |

`PublicProjectMemberOverride` : `{ id, projectId, userId, allow, deny }`. `deny` l'emporte sur `allow` en cas de chevauchement ; seule la permission `ADMINISTRATOR` passe outre.

**Forme de création/mise à jour d'un projet** :

```json
{
  "slug": "mon-projet",
  "title": "Mon projet",
  "status": "draft",
  "visibility": "PRIVATE",
  "seriesStatus": "ONGOING",
  "authors": [{ "authorId": 1, "role": "WRITER" }],
  "teams": [{ "teamId": 1, "role": "TRANSLATOR" }],
  "tags": ["action"],
  "externalLinks": ["https://..."]
}
```

- Rôles auteur (`ProjectAuthorRole`) : `WRITER | ARTIST | AUTHOR | ILLUSTRATOR | OTHER`.
- Rôles team (`ProjectTeamRole`) : `TRANSLATOR | EDITOR | CLEANER | TYPESETTER | PUBLISHER | OTHER`.
- `visibility` (`ProjectVisibility`) : `PUBLIC | UNLISTED | PRIVATE | ARCHIVED`.
- `seriesStatus` : `ONGOING | COMPLETED | HIATUS | LICENSED | CANCELLED`.

## Fichiers uploadés

Les images (couvertures, bannières, pages de chapitres, avatars) sont stockées sur disque (`data/webcomics`) et servies statiquement sous `/uploads/*`.

## Notes de conception

- Le contrat public (formes `Public*`, rôles, statuts) est intentionnellement stable — voir `db/services/*.services.ts`.
- `authors`/`teams` sur un projet sont additifs : les champs historiques (`authorName`, `team`) continuent de représenter le premier crédit pour ne pas casser les vues compactes.
- Les badges/niveau/série de lecture (`achievements`) sont calculés à la volée, jamais stockés.
